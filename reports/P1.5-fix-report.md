# P1.5 修复报告：OptTool.exe 启动崩溃（缺失 .pri 资源文件）

## 1. 问题现象

发布产物 `dotnet publish -c Release -o G:\cft\dist` 能构建成功，但
`G:\cft\dist\OptTool.exe` 一启动就崩溃：

- 退出码：`-1073741189`（`0xC000027B`，Stowed Exception）
- 崩溃模块：`Microsoft.UI.Xaml.dll`

## 2. 根因

应用自己的 PRI 资源文件 `OptTool.pri` 在构建输出目录里存在：

```
G:\cft\src\OptTool\bin\Release\net10.0-windows10.0.26100.0\win-x64\OptTool.pri
```

但它没有被复制到发布输出目录 `G:\cft\dist\`。

WinUI 3 在 XAML 初始化阶段需要加载应用自己的 `.pri` 资源文件（包含 XAML
类型信息、字符串、图片等资源索引）。发布目录缺失该文件时，`Microsoft.UI.Xaml.dll`
在初始化资源加载链时抛出 Stowed Exception，进程以 `0xC000027B` 退出。

已验证：手工把 `OptTool.pri` 复制到 `G:\cft\dist\` 后，程序能正常启动并弹出窗口，
确认根因成立。

## 3. 修复方案

在 `G:\cft\src\OptTool\OptTool.csproj` 末尾加入一个 MSBuild 目标，在 `Publish`
目标执行完成后，把 `$(OutDir)$(TargetName).pri` 复制到 `$(PublishDir)`。

实际写进 csproj 的片段原文：

```xml
  <!--
    WinUI 3 非打包自包含发布时，应用自己的 .pri 资源文件不会被默认复制到 PublishDir，
    导致 XAML 初始化时因找不到资源而崩溃（0xC000027B / Stowed Exception）。
    在 Publish 之后显式把 $(OutDir)$(TargetName).pri 复制到发布目录。
  -->
  <Target Name="CopyPriToPublish" AfterTargets="Publish">
    <Copy SourceFiles="$(OutDir)$(TargetName).pri"
          DestinationFolder="$(PublishDir)"
          SkipUnchangedFiles="false"
          Condition="Exists('$(OutDir)$(TargetName).pri')" />
  </Target>
```

说明：`$(OutDir)` 解析为
`bin\Release\net10.0-windows10.0.26100.0\win-x64\`（即 `.pri` 所在目录），
`$(PublishDir)` 解析为 `G:\cft\dist\`。`Condition` 保证源文件不存在时不报错。

## 4. 验证记录

严格按任务要求的 1–5 步顺序执行，全部使用真实命令与真实输出。

### 第 1 步：删除发布目录

命令：

```powershell
Remove-Item 'G:\cft\dist' -Recurse -Force
```

输出：

```
dist removed, exists=False
```

### 第 2 步：重新发布

命令（在 `G:\cft\src\OptTool` 下，`NUGET_PACKAGES=G:\nuget-cache`）：

```powershell
dotnet publish -c Release -o G:\cft\dist
```

输出（末尾）：

```
正在确定要还原的项目…
  所有项目均是最新的，无法还原。
  OptTool -> G:\cft\src\OptTool\bin\Release\net10.0-windows10.0.26100.0\win-x64\OptTool.dll
  OptTool -> G:\cft\dist\
```

退出码 `0`，发布成功。

### 第 3 步：检查 `G:\cft\dist\OptTool.pri` 是否存在（发布流程自动产出，非手工复制）

命令：

```powershell
Test-Path 'G:\cft\dist\OptTool.pri'
Get-Item 'G:\cft\dist\OptTool.pri' | Select-Object Name,Length,LastWriteTime
```

输出：

```
OptTool.pri exists: True

Name          : OptTool.pri
Length        : 2196296
LastWriteTime : 2026/10/06 16:00:24
```

`.pri` 文件由发布流程自动产出，大小 2,196,296 字节，未做任何手工复制。

### 第 4 步：启动 `G:\cft\dist\OptTool.exe`，确认 10 秒后进程仍在

命令：

```powershell
$p = Start-Process -FilePath 'G:\cft\dist\OptTool.exe' -PassThru
Start-Sleep -Seconds 10
$p.Refresh()
Write-Host "after 10s HasExited=$($p.HasExited) alive=$(-not $p.HasExited)"
```

输出：

```
after 10s HasExited=False alive=True
```

进程启动 10 秒后仍存活，未发生立即崩溃。

### 第 5 步：关闭进程

命令：

```powershell
Stop-Process -Id $p.Id -Force
```

输出：

```
process stopped
```

进程已正常关闭。
